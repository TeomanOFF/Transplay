# Transplay
Real-time data that mimics a station/on vehicule display with many themes to choose from (vibecoded) (hobby not serious)

This is a hobby project that has been **vibecoded** with **Qwen-4Max**

It allows you to mimic a **Station** / **On Vehicule** sign
- **Station**
> Shows the left time since other arrivals
> settings allows you to choose more than one lane
- **On Vehicule**
> Shows the next stops and their time to arrive there

Many themes for both modes, some are realistic, some are less

## Structure
Just **one** html file that has **JS and CSS** that can be ran one any device with a web browser that can open html files
